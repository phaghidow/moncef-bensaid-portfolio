# Moncef Bensaid — Portfolio

Bilingual portfolio built with Next.js, React, TypeScript, Tailwind CSS, and
`next-intl`. The site includes project case studies, image and video showcases,
and downloadable French and English resumes.

## Local development

Requirements: Node.js and npm.

```sh
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```sh
npm run lint
npm run build
```

## Deploy on Vercel

1. Import this GitHub repository into [Vercel](https://vercel.com/new).
2. Keep the detected Next.js framework preset and default build settings.
3. Deploy. No environment variables are required for the default configuration.
